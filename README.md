# 世界历法地图 · World Calendar Map

An interactive world map of the calendar systems in use today. Countries using more than one calendar are drawn with diagonal stripes; click a legend chip to highlight every country that uses that calendar family, and click a country to see its calendars and current years.

**Live:** https://matt-v50.github.io/WorldCalendar/

- Data: [Wikipedia · List of calendars](https://en.wikipedia.org/wiki/List_of_calendars), country assignments supplemented by hand; years as of Nov 2026 (approximate).
- Borders: [Natural Earth](https://www.naturalearthdata.com/) via `world-atlas` (50m), projected to Natural Earth I. Illustrative only.

Single self-contained `index.html`; deployed by GitHub Actions to Pages on every push to `main`.
